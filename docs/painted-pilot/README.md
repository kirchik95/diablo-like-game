# Пилот «рисованное 2D» — фаза 2

Скриншоты пилота от 2026-10-25. Сборка `ff1714f0`. Код пилота живёт отдельно и в игру не входит. Игра остаётся пиксельной с HD-2D, пока решение о стиле не принято.

## Сборка пилота
Слева вверху — кадр-цель. Справа — фаза 1. Внизу — фаза 2: компьютер в покое и бой с тремя гончими на телефоне.
