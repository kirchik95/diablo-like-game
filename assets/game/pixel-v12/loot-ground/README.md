# Добыча на земле

Спрайты мира для предметов на земле (§5.4). Каждая основа оружия и каждая реликвия лежит плашмя в нашем виде 2:1. Свечение редкости, тень и блик — отдельные кадры. Рендерер складывает их в стопку и может их тонировать.

Скрипт `scripts/build-loot-ground.py` рисует каждый пиксель из карт и формул. Генерации изображений, сети и новых зависимостей нет.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `loot-ground.png` | Атлас: ячейка 48×48, 8 столбцов × 4 ряда, 30 кадров. Якорь `[24,34]` у всех кадров. |
| `camp-supplies.png` | Атлас припасов лагеря: ячейка 72×52, 2 кадра. Якорь `[36,28]`. |
| `frames/*.png` | Каждый кадр отдельным файлом того же размера. |
| `manifest.json` | Контракт: нарезка, якоря, `opaqueBounds`, связи с данными, SHA-256 всех PNG. |
| `contact-sheet.png` | Обзорный лист (описание ниже). |

## Кадры

Порядок в `loot-ground.png` (индекс `i`: x = (i % 8)·48, y = ⌊i / 8⌋·48):

1. Ряд 0, предметы: `item-novice-knuckles`, `item-bronze-knuckles`, `item-pilgrim-knuckles`, `item-novice-staff`, `item-ash-staff`, `item-pilgrim-staff`, `item-quiet-thunder`, `item-crane-neck`.
2. Ряд 1, тени: `shadow-<id>` в том же порядке.
3. Ряд 2: `ring-common-0/1`, `ring-rare-0/1`, `ring-relic-0/1`, `glint-0`, `glint-1`.
4. Ряд 3: `beam-common-0/1`, `beam-rare-0/1`, `beam-relic-0/1`.

Связи с данными:

- `manifest.weapons[id]` — кадр для `WEAPON_BASES[id]`.
- `manifest.relics[id]` — кадр для `RELICS[id]`. Предмет-реликвия берёт кадр реликвии, а не кадр основы.
- `manifest.rarity[rarity]` — кадры `ring` и `beam` для `RARITIES[rarity]`, цвет токена и высота луча.
- `manifest.frames[name].shadow` — тень предмета. `manifest.frames[name].glint` — пиксель для блика.
- `manifest.campSupplies.full` и `.empty` — ткань с оружием и пустая ткань.

Вид предметов повторяет значки `assets/ui/pixel-v5/icons/`:

| Кадр | Рисунок |
| --- | --- |
| `item-novice-knuckles` | Железные кольца, деревянная рукоять |
| `item-bronze-knuckles` | Бронзовые кольца и рукоять |
| `item-pilgrim-knuckles` | Тёмное железо, шипы, коралловая рукоять |
| `item-quiet-thunder` | Бронза, искры духа над кольцами, коралловая рукоять |
| `item-novice-staff` | Простое дерево, две обмотки, железный низ |
| `item-ash-staff` | Светлый ясень, железные концы |
| `item-pilgrim-staff` | Тёмное дерево, янтарный пояс, янтарное кольцо на конце, коралловая лента |
| `item-crane-neck` | Янтарный лак, белая перевязь, белая шея журавля с коралловым теменем |

## Якорь и масштаб

- Масштаб: 32 px на 1 ед., как у всех спрайтов мира. Тянуть без сглаживания (`nearest`, без mipmaps).
- Якорь — угол пикселя: точка x = 24,0, y = 34,0 в кадре 48×48. Это точка земли под серединой предмета.
- Поставь якорь в проекцию `ground.x, ground.y`. Все слои стопки встают в ту же точку без сдвига.
- Посох лежит вдоль мировой оси x и занимает около 1,24 ед. Кастет повёрнут чуть от оси.
- Размер предметов по `opaqueBounds`: кастеты 22–24 × 13–16 px, посохи 30–38 × 17–22 px.
- Предмет крупнее значка 16 px из §5.4. Посох длиной 16 px не читается как посох.
- Кадр можно отразить по горизонтали вместе с тенью. Якорь при этом не меняется. Блик: x → 47 − x.

## Стопка слоёв

`manifest.stack` задаёт порядок от дальнего слоя к ближнему:

```
  5  glint   ──  блик раз в 2 с, в точке frames[item].glint
  4  item    ──  предмет, двоичная альфа
  3  beam    ──  луч растёт из якоря, стоит ЗА предметом
  2  shadow  ──  цвет #141223, рисовать с альфой 0,4
  1  ring    ──  кольцо на земле вокруг якоря
     ─────────── земля ───────────
```

## Заметки для рендерера

1. Предмет, тень и кольцо лежат на земле. Рисуй их как плоский рисунок земли (`layOnGround` в `src/pixel-scene.js`). Тогда монах всегда стоит поверх предмета.
2. Предмет и тень имеют двоичную альфу. Для них подходит alpha test.
3. Тень заменяет `createShadow` для предмета. Рисуй её с альфой 0,4 (`manifest.shadow.drawAlpha`, как `SHADOWS.item`). Не рисуй обе тени.
4. Кольца, лучи и блик имеют ступенчатую альфу. Рисуй их с alpha blend. Alpha test с порогом 0,5 срежет слабое пятно и ореол.
5. Луч стоит за предметом. Если 2D-оверлей рисует луч поверх сцены, рисуй только строки выше `opaqueBounds[1]` предмета.
6. Предмет лежит. Не поднимай его на `ITEM_REST` и не качай. Пульс дают кадры кольца и луча.
7. Смена кадров: кольцо 0/1 каждые 0,5 с, луч 0/1 каждые 0,3 с (`manifest.timing`).
8. Блик: кадр `glint-0` или `glint-1` на 0,16 с раз в 2 с. Сдвиг кадра = `frames[item].glint − anchor`.
9. При `prefers-reduced-motion` показывай кадр 0 кольца и луча. Блик не показывай.
10. Цвет уже в кадрах. Тонировать не нужно. Кадры `common` почти белые, поэтому их можно тонировать умножением.
11. Редкость читается и без цвета. Обычное: четыре короткие дуги, луч 14 px. Редкое: пунктирное кольцо, луч 24 px. Реликвия: сплошное кольцо, внутреннее пунктирное, четыре искры, луч 28 px со звездой.
12. Наведение и подпись: прямоугольник `opaqueBounds` кадра предмета.

Припасы лагеря:

1. `camp-supplies.png` — плоский рисунок земли, как ковёр лагеря. Якорь `[36,28]` — центр ткани.
2. Ткань 1,44 × 1,36 ед. (`frames['camp-supplies'].cloth`, полуразмеры по осям x и y).
3. До нажатия E показывай `camp-supplies`. После E показывай `camp-supplies-empty`.
4. Место выбирает раскладка лагеря. Хорошее место — рядом с `supply-cache` (`src/camp-layout.js`).

## Обзорный лист

`contact-sheet.png`, сверху вниз:

1. Три ряда ×3: каждый предмет с тенью на траве, земле и плитах.
2. Три ряда ×3: полная стопка в обычной для предмета редкости. Кадры 0, 1, 0.
3. Ряд ×3: посох во всех редкостях и обоих кадрах, кастет-реликвия, блик на посохе пилигрима.
4. Масштаб игры: 5:6 и затем ×2, как при окне 1174×813. Все предметы вокруг монаха на трёх землях.
5. Припасы ×3: с оружием, пустая ткань. Справа — масштаб игры рядом с монахом.
6. Атлас ×2 на тёмном фоне. Видны ступени альфы.

Земли — настоящие поверхности `camp-grass.png`, `camp-earth.png` и `courtyard-flagstone.png` в проекции рендерера.

## Пересборка и проверка

Из корня репозитория (проверено на Python 3.14.4 и Pillow 12.3.0):

```sh
python3 -B scripts/build-loot-ground.py
python3 -B scripts/build-loot-ground.py --verify-only
node --test tests/loot-ground-assets.test.js
```

`--verify-only` рисует всё в памяти и сравнивает байты. Скрипт ничего не пишет. Код выхода не 0, если файл отличается, отсутствует или лишний. Байты совпадают только с той же версией Pillow.

## Ограничения

- Анимации падения нет. Столб на 1,2 с после падения (§5.4) рендерер рисует сам или собирает из кадров `beam`.
- Предмет редкой редкости использует кадр своей основы. Редкость показывают только кольцо и луч.
- Один ракурс. Поворотов предмета нет.
