# Рисованные референсы

Девять листов с монахом, кастомизацией, жителями лагеря, тремя монстрами, двумя локациями и окружением. Они развивают исходный выбор из `../visual-exploration-01/`. Три доски «Истоков» удалены из Paper; их [PNG @2x](../paper-archive/origins-hand-drawn/) сохранены в архиве. Старые экспорты остаются на месте.

Во время работы пользователь выбрал упрощённый pixel art. Актуальный набор находится в [pixel-art-01](../pixel-art-01/README.md); эти рисунки сохраняются как референсы конструкции, костюмов и атмосферы.

Доска затопленной крипты удалена из Paper. Её [PNG @2x](../paper-archive/references-locations/08-location-flooded-crypt.png) сохранён в архиве. Файл `08-flooded-crypt-keyart.png` остаётся старым экспортом. Крипта исключена из плана игры.

`session-manifest.json` содержит историю всего художественного прохода, включая промпты, источники, экспорты и отклонённые варианты. Наличие идентификатора отклонённого узла не означает, что этот узел ещё существует в Paper.
