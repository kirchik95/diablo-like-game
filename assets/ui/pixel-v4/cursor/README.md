# Пиксельные курсоры

Три курсора в палитре HUD. Один пиксель рисунка равен 2 CSS px, как базовая единица HUD `--u`.

| Курсор | Где | Размер 1× | Точка |
| --- | --- | --- | --- |
| `reticle` | игровое поле `#game` | 30×30 | 15, 15 — коралловый центр, точка прицела |
| `arrow` | меню и панели | 24×32 | 0, 0 — кончик |
| `arrow-active` | кнопки и выбор облика | 24×32 | 0, 0 — кончик |

Для каждого курсора есть версия `@2x` для экранов высокой плотности. В CSS курсоры заданы через `image-set()` с системным запасным вариантом: `crosshair`, `default`, `pointer`.

Пересборка и проверка:

```sh
python3 -B scripts/build-cursor-assets.py
python3 -B scripts/build-cursor-assets.py --verify-only
```

Рисунки заданы ASCII-картами в скрипте. `manifest.json` хранит размеры, точки и SHA-256 файлов; тест `tests/adventure-ui-hud.test.js` сверяет хэши и правила CSS.
