# Пиксельные курсоры

Три курсора в палитре HUD. Пиксель рисунка равен единице HUD `--u`.

| Курсор | Где | `--u` 2px | `--u` 3px | `--u` 4px и больше | Точка |
| --- | --- | --- | --- | --- | --- |
| `reticle` | игровое поле `#game` | 30×30, точка 15, 15 | 45×45, точка 22.5, 22.5 | 60×60, точка 30, 30 | центр картинки |
| `arrow` | меню и панели | 24×32 | 36×48 | 48×64 | 0, 0 — кончик |
| `arrow-active` | кнопки и выбор облика | 24×32 | 36×48 | 48×64 | 0, 0 — кончик |

Порог 3px — экран от 1920×1080. Порог 4px — экран от 2560×1440. Если `--u` равен 5px или больше, на экране остаётся курсор 4px.

У каждого масштаба есть файл 1× и файл `@2x` для экранов высокой плотности. Дополнительные имена: `reticle-u3.png`, `reticle-u3@2x.png`, `reticle-u4.png`, `reticle-u4@2x.png`. Так же названы `arrow` и `arrow-active`. Базовые файлы без суффикса — это масштаб 2px.

В CSS сначала стоит системный курсор: `default`, `crosshair` или `pointer`. Затем идёт `image-set()` с точкой. У прицела точка — центр картинки. У стрелки точка — кончик.

Пересборка и проверка:

```sh
python3 -B scripts/build-cursor-assets.py
python3 -B scripts/build-cursor-assets.py --verify-only
```

Рисунки заданы ASCII-картами в скрипте. `manifest.json` хранит размеры, точки и SHA-256 файлов для каждого масштаба. Тест `tests/adventure-ui-hud.test.js` сверяет хэши и правила CSS.
